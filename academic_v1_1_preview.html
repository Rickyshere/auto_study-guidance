深度学习核心架构：梯度传播、自注意力与训练稳定性

在深层神经网络训练过程中，非线性激活函数决定了表征能力与梯度回传稳定性。 ReLU 的导数在正区间恒为 1，能够显著缓解深层网络的梯度消失问题 ， 而 Sigmoid 在两端饱和区梯度趋近于 0，更容易引发浅层参数更新停滞 。

一、Scaled Dot-Product Attention 缩放机制

在 Transformer 多头自注意力中，点积 QKᵀ 的方差随向量维度 d_k 线性增长。 除以 √d_k 可将注意力 logits 方差归一化至 1，防止 Softmax 落入梯度极小的饱和区 。

Attention(Q, K, V) = softmax( (Q · Kᵀ) / √d_k + Mask_causal ) · V scores = torch.matmul(q, k.transpose(-2, -1)) / math.sqrt(d_k) # Var(q·k) = d_k -> Var(scaled) = 1.0

注：上方公式与代码块包裹在 overflow-x: auto 容器内，确保窄屏与移动端不会撑破卡片边界。

二、残差连接（ResNet）与 LayerNorm 协同作用

跳跃连接（Skip Connection）将恒等映射 x 直接加到子层输出 F(x) 上，为反向传播开辟无衰减高速通路 ； 配合 Pre-LayerNorm 结构 可在 Transformer 训练早期免除冗长 Warmup，提升收敛鲁棒性 。

背面 · 核心定义与溯源

Var(∑ qᵢ·kᵢ) = d_k ⇒ Var(q·k / √d_k) = 1
