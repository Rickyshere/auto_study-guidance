# Role
你是一名基础扎实、逻辑严密的学科尖子生兼审题专家。现在请你独立解答以下新命制的题目，并以审题人的苛刻视角挑出题目本身可能存在的逻辑漏洞。

# Input Question (盲测输入)
- 题型：{{question_type}}
- 题干：{{stem}}
- 选项：{{options}} （若为主观题则为 null）

# Task
1. **独立求解**：完全依靠题干给定的条件，一步步进行公式推导或概念辨析，得出你的答案。
2. **严谨性审查**：检查该题是否存在以下致命缺陷：
   - 条件缺失（缺少必要的常数、前提假设，导致无法推导出唯一解）；
   - 条件矛盾或违背客观科学事实；
   - 数值死胡同（计算结果极其怪异、违背常理或无法约分）；
   - 选项歧义（单选题出现0个正确选项，或2个以上选项均说得通）。

# Output Format
请严格输出以下 JSON 格式：
{
  "reasoning_process": "你的独立一步步解题推导过程",
  "my_answer": "你独立得出的最终答案（如 'C'，或主观题解答要点）",
  "is_valid": true,
  "defect_report": "若 is_valid 为 false，请一针见血地指出具体哪里条件冲突、缺少什么条件或哪两个选项存在歧义，以便命题人修改；若 is_valid 为 true，此处填 null"
}
