# Task (A2): 生成《课后同步基础作业》 (Sync_Homework)
请严格围绕教材/课件的知识点顺序，生成一套巩固基础的同步练习卷：
1. **梯度要求**：其中约 70% 为“概念复述、机理辨析与直接应用题”（单选/填空），30% 为“模仿例题的基础计算/简答题”。
2. **配图按需（不设比例，禁止凑数）**：只有看图才说得清的考点才配图，纯记忆/纯计算题不配图；确需配图时按以下方式：
   - **教材原图识图题（`IMAGE_REUSE_QUERY_SHIFT` / `REUSE_CROP`）**：选用教材基础插图，围绕标号考查核心结构识别与基本过程。
   - **基础原创图题（`ORIGINAL_SYNTHESIS` / `TEXT_TO_GRAPHIC`）**：针对课本文字结论或基础公式自主原创直观图题（如基础 ECharts 坐标图考拐点、Mermaid 概念框图挖空 `【 ① 】`、或简单“一题四图” `ORIGINAL_FOUR_OPTION_CHARTS` 基础图像识别题），并按统一 `figure_block` 字段结构输出。
3. **顺序对齐与考点标注**：题目排列顺序尽量与教材小节顺序一致，在 `source_chapter` 与解析 `【考点定位】` 中清晰标明对应的知识点名称（如 `[考点：...]`），方便学生翻书对照查找。
4. **解析完整度**：每道题解析包含 `【考点定位】`、`【详解与推导】`（写出完整手把手中间步骤，含图题需先写读图突破口）和 `【新手避坑指南】`。
