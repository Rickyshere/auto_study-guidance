# Task (A1): 生成可打印的《零基础详细自学案（附带例题）》 (Guided_Study_Guide)
请基于上传的教材/课件内容，按章节生成一份适合打印自学的讲义：

1. **【导学与直觉建立】**：用一段话和1个生活化类比，说明本节到底在解决什么问题。
2. **【核心概念精讲】**：
   - 提取所有基础概念，采用“标准定义 + 大白话翻译 + 关键特征加粗”格式。
   - 推导核心公式/机理时，必须列出每一步的依据，并标注公式中每个符号的物理意义与单位。
   - 讲义正文**不要插入任何原书/课件截图或图片链接**（严禁输出 `![...](...)`）；机制、装置、流程一律用文字、Markdown 表格与 LaTeX 公式讲清楚。
3. **【母题手把手精析】（至少 4 道典型例题，每 1 个核心知识点配 1 道典型例题）**：
   - **【题目】**：交代清晰条件、待求目标或完整情景，紧扣刚讲完的概念。
   - **【破题眼（怎么想）】**：告诉初学者看到题干哪个词，应该联想到刚才学的哪个知识点。
   - **【规范作答步骤（怎么写）】**：提供可直接作为考场答题模板的完整 Step 1, Step 2, Step 3 步骤。
   - **【新手避坑指南】**：点明初学者在这一步最容易犯的1个低级错误。
4. **【随堂微自测】**：每节末尾附2道即时巩固填空/判断题；参考答案统一放在全篇末尾，并用单独一行 `<div class="page-break"></div>` 与正文分隔（导出器会另起一页，方便对折遮挡答案）。

4. **【核心概念与图文拆解 + 教材原图/原创流程图】**：
   - 优先引用提取到的教材原图资产并附带 `【🔍 零基础三步读图指南】`；若教材仅有大段纯文字机制，主动原创绘制一段直观 **Mermaid `graph LR` 分步流程图**。
5. **【母题手把手精析（含“原创含图母题”）】**：
   - 每章至少包含 1~2 道含图例题（支持结合教材原图，或调用 `ORIGINAL_SYNTHESIS` 为核心公式/规律原创绘制清晰的基础坐标图 ECharts 或物理/生理基础示意图 SVG）。
   - 每道含图例题在四步卡片中清晰写明 `【👀 读图与破题眼（第一步先看横纵坐标/箭头起点）】`。
