# Task (A3): 生成《零基础达标单元检测卷》 (Unit_Test_Paper)
请按照标准考试卷格式生成一套单元过关检测卷：
1. **难度控制**：整体难度控制在 **基础:中档 = 8:2**，杜绝偏题怪题，重在检验学生是否真正吃透了教材基本盘。
2. **卷首信息栏（写入 `instructions` 字段）**：试卷标题、适用章节、建议用时、总分，以及可供打印后手写的填写栏 `姓名：__________  日期：__________  得分：__________`。
3. **题型与计分**：按题型数量契约生成单项选择题、核心概念填空题、基础综合与规范解答题，分值分布合理。
4. **配套评分标准**：每道主观题的 `answer` 与 `explanation` 必须给出按步骤给分的评分标准（如 `【得分点1】写出公式得2分；【得分点2】代入数据计算得3分`）。
