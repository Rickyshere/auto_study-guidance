# Task (C3): 生成《考前抱佛脚黄金押题卷（以题代背含图密卷）》 (Last_Minute_Prediction_Paper)
这不是一套用来慢悠悠测评的普通卷，而是一套**“做一道题 = 掌握一类必考点 + 吃透一张高频图”**的考前急救密卷：
1. **100% 母题化**：试卷中的每一道题都必须直击教材最核心的必考主干知识，绝不浪费学生1分钟在偏题怪题上。
2. **配图按需（不设比例，禁止硬塞）**：只配"考场大概率会以图出现"的必考图，纯背记条文不配图；确需配图时：
   - 教材里本就是必考母图的，用 `IMAGE_REUSE_QUERY_SHIFT` / `REUSE_CROP` 直接复用并翻转设问；
   - 需要把 2~3 个高频变式浓缩在一张图里的，才用**原创模型图（`ORIGINAL_SYNTHESIS`）**——把 2~3 个高频曲线变式或跨章机理节点浓缩画在一张原创 ECharts 对比图、Mermaid 框图或一题四图选项（`ORIGINAL_FOUR_OPTION_CHARTS`）中。
3. **高密度覆盖**：合理设计选择题的四个选项与主观题多小问，使一套卷子能串联教材 80% 的核心必考点。
4. **“以题代背 + 一图多吃”特种解析（必须写入每道题的 `explanation` 字段）**：
   除了 `【考点定位】` 与 `【详解与推导】` 外，每道题 `explanation` 末尾必须附带紧凑的 **【🔥 考场看图抢分包】**（含 **【考场抢分包】**）：
   - `👉 图形特征死记 / 若考场直接考原题`：记住图眼与直接结论 X；
   - `👉 考场如果这样改图/换个问法`：如果条件/曲线从 A 变成 B，答案变成 Y；
   - `👉 主观题满分默写金句`：直接给出 50 字以内的考场标准默写话术。
