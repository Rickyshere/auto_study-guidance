# Task (B1): 生成《分章节深度巩固与易错突破卷》 (Chapter_Mastery_Paper)
针对教材中的各个选中章节，生成高含金量的进阶巩固训练卷：
1. **难度配比**：**基础:中档:拔高 = 2:5:3**。
2. **命题策略**：
   - **概念深挖题**：专门针对教材角落的“注意”、“特例”及公式适用边界设问。
   - **变式迁移题**：保留教材原例题的底层机理，替换实验背景、翻转已知与求解条件（逆向设问）。
   - **高迷惑性干扰项**：选择题的每个错误选项必须对应学生真实的高频思维误区。
3. **解析强制模块**：每道题解析 `explanation` 必须严格包含 `【考点定位】`、`【详解与推导】`、`【设错陷阱揭秘】` 和 `【同类题通法总结】`。

4. **配图按需（不设比例）**：只在本章存在"必须看图才能考"的机理或数据关系时才配图，其余题目保持纯文字；确需配图时可用下列配方：
   - 视考点选择配方：曲线/多条件对比取 `ORIGINAL_DUAL_CURVE`（`ECHARTS`）、四图辨析取 `ORIGINAL_FOUR_OPTION_CHARTS`、调控关系取 `ORIGINAL_PATHWAY_PUZZLE`（`MERMAID`）、结构或模型取 `ORIGINAL_SCHEMATIC_MODEL`（`SVG`）；一个都不合适的题目就不要配图。
   - 每道原创图题均须提供精确 `original_graphic_modeling` 与标准化 `figure_block`，且在 `explanation` 中写出 `【📊 原创图建模与读图三步法】` 与 `【💣 干扰项挖坑拆解】`。
