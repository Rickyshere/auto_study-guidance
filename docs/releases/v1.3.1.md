# Auto Study Guidance v1.3.1 更新公告
## 新增
- **分节练习自动就绪**：讲义一生成，程序就在后台把每一节的练习排好队，打开就能做，不用再点「生成」。还没轮到的那一节会显示「准备中」，好了自动可点。
- **导学页不再逼你做题**：知识地图、导学、公式速查这类小节标为「只读」，点「标记本节已读完」就能进下一节；只有真正讲知识的第 N 节才要求读完 + 做完练习。
## 修复
- **讲义被切成了两份**：以前讲义被切了两次（页面按标题切出 11 段，练习按另一套切出 8 段），两边对不上，于是「进入下一节」永远灰着、练习按钮写着「无对应练习」。现在只有一套划分，你这份讲义是「知识地图 + 7 节 + 公式速查」共 10 节。
- **参考答案、检测卷不再算一节**：答案、单元检测卷、附录、目录不再混进逐节学习，检测卷仍留在「单元检测」。
- **点开有节时可能整页白掉**：一个初始化顺序的问题会让讲义页在有对应练习时直接崩，已修。
- **高亮擦不掉**：以前划下的高亮没法撤销。现在点一下高亮处会浮出「取消高亮」，点掉即恢复原样；删页边批注时正文里的高亮也一起还原。
- **页边批注串到别的节**：页边栏现在只显示当前这一节的批注，翻到下一节不会再看到上一节的卡片。
> 刷新页面即可；桌面版需重启程序。
