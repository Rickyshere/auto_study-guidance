# Auto Study Guidance v1.2.1 更新公告

本次更新只修一件事：**热更新现在会真的把文件更新完整**。

## 新增
- **更新会补齐所有文件**：除拉取代码外，还会自动安装有变化的依赖（pip / npm）、重建前端界面文件、重编译桌面程序本体。以前这三步要手动做，漏做就会出现"更新成功但打不开新界面"。
- **更新结果有明细**：更新完成后逐条列出每一步做了什么、成功还是失败，而不是一句"已更新"。

## 减少
- 少了"更新完还要自己去跑一遍命令"的隐性步骤；勾选项默认全开，一般直接点更新即可。
- 少了误报：以前在离线副本上点更新，会显示"已是最新版本"；现在不会了。

## 修复
- **离线副本不再装作能更新**：如果当前目录不是 Git 仓库（比如下载的压缩包、拷贝出来的文件夹），会明确提示"当前安装无法热更新"，并给出重新下载安装包的建议，更新按钮同时置灰。
- **程序本体也会一起更新**：桌面版正在运行时无法覆盖自身，此时会排队处理——关闭程序窗口后自动完成重编译，下次打开即是最新版本；日志留在 `backend/data/logs/update_build.log`。
- **只差构建产物的情况也能修**：即使代码已是最新，只要前端界面文件或程序本体比源码旧，更新也会把它们补齐。
- **依赖安装失败不再假装成功**：会明确报出失败原因，并提示对应的手动命令。

> 更新后请刷新页面；桌面版需重启程序。
