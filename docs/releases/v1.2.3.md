# Auto Study Guidance v1.2.3 更新公告

## 新增
- **识别完先给你看**：上传后不再闷头往下跑，而是把识别出来的文字整篇摊开，核对完才继续。
- **错字能就地改**：哪一节的字认错了，直接在原文里改，改完照常往下生成。
- **随时回看**：左侧工作区新增「核对识别文字」，之后任何时候都能打开回看或再改。
- **认得太差可以重来**：面板里直接「重新上传」，不用退回首页。

## 减少
- 不再等资料全生成出来才发现整篇是错字，白等一轮。
- 不用为了改一个公式把整本书重新传一遍。

## 修复
- **改了文字就重新确认**：订正后确认状态自动失效，不会出现「确认过的」和「实际用的」不是同一份文字。
- **识别为空会明说**：一个字都没认出来时明确警告，要再点一次才继续，不再悄悄生成。
- **印刷件不再漏公式源码**：讲义页眉的「覆盖章节 / 核心聚焦」、答案速查表、解析溯源里残留的 `$...$`、`\mathrm` 现在都正常排版。
- **难度不再露英文代号**：打印件里不会出现 `exam_sprint` 这种内部标识，改为「考前冲刺」。
