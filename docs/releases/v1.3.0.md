# Auto Study Guidance v1.3.0 更新公告

## 新增
- **核对识别结果成了正式一步**：流程改为「1. 资料上传与 OCR → 2. 识别结果确认 → 3. 场景选择与生成」。确认页占据整个主界面（左边列节、右边大编辑区），不再是逼仄的小弹窗，可以直接逐节改错字。
- **不用重新上传就能重识别**：确认页里有「重新识别」，换好 OCR 引擎点一下按整本重跑，进度实时显示。
- **识别体检**：每份资料都记录「扫描页总数 / 成功页数 / 失败页号」，OCR 到底有没有用一目了然。

## 修复
- **资料跑到 D 盘根目录**：程序把工作目录写死成 `D:\auto_study_guidance`，换台电脑就会凭空新建这个文件夹。现在一律跟着程序位置走。
- **31 页的书只识别出 2 页**：逐页识别时一页出问题，后面几十页会被静默跳过，而总字数不为 0，看着像成功。现在每页都有记录。
- **本地识别把整页图的乱码塞进正文**：会把页面图片的超长编码当文字吐出来，几万字乱码混进教材；现在会被清掉。
- **开头几页被整段丢掉**：按标题切章节时第一个标题之前的页会漏掉，现在单独成为「开头 N 页」。
- **选择题后出现两个括号**：题干本来带了「（　）」而程序没认出来，又补了一个；现在各种写法都能识别。
- **云端识别偶发"成功但空"**：现在自动重试一次，失败原因也会攒下来告诉你。

> 刷新页面即可；桌面版需重启程序。
