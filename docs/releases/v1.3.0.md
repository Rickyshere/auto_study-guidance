# Auto Study Guidance v1.3.0 更新公告

## 修复
- **资料跑到 D 盘根目录**：程序把工作目录写死成 `D:\auto_study_guidance`，换台电脑或换个安装位置就会凭空新建这个文件夹，你的东西就不在项目自己的文件夹里了。现在一律跟着程序所在位置走。
- **31 页的书只识别出 2 页**：扫描件逐页识别时，一页出问题后面几十页会被静默跳过，最后只留一小段，而总字数不为 0，看着像成功。现在每页都有记录，不会再被跳过。
- **本地识别把整页图的乱码塞进正文**：本地 OCR 会把页面图片的一长串编码当文字吐出来，几万字乱码混进教材；现在会被清掉。
- **开头几页被整段丢掉**：按标题切章节时第一个标题之前的页会漏掉，现在单独成为「开头 N 页」。
- **云端识别偶发"成功但空"**：现在自动重试一次，失败原因也会攒下来告诉你。

## 新增
- **不用重新上传就能重识别**：核对面板多了「重新识别」，换好 OCR 引擎点一下按整本重跑，进度实时显示。
- **识别体检**：每份资料记录"扫描页总数 / 成功页数 / 失败页号"，OCR 到底有没有用一目了然。

> 刷新页面即可；桌面版需重启程序。
