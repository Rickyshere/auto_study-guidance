# Auto Study Guidance v1.2.2 更新公告

## 新增
- **分节练习**：练习拆成「分节练习」和「章节测验」两个入口。分节练习只考讲义里某一节，讲义有几节就能练几节。
- **讲义可跳转**：讲义顶部新增小节导航，点标题跳到对应小节，每节旁有「练本节」可直接做题。
- **练习有缓存**：同一节只生成一次，再点开秒开；讲义重生成后自动失效。
- **OCR 状态看得懂**：设置里写明「选的是谁 / 生效的是谁 / 能不能用」，卡片标出运行状态。
- **OCR 可卸载**：已安装的引擎新增卸载按钮（之前只有安装）。

## 减少
- 作业不再混在一起做，一次只面对一节。
- 改了 OCR 选择没保存会提示「待保存」，不用再猜。

## 修复
- **「收起答案与解析」点了没反应**：选择题作答后解析被强制永久展开，已修好。
- **作答前不能看答案**：未作答时按钮显示「先作答，再查看答案与解析」且不可点击；填空没填内容也不会放行「提交并核对」。
- **试卷说明里的公式**：打印版「考生注意」里的 `$...$` 之前会被当成普通文字印出来，现在正常排版。
- **选了云端识别还是「未就绪」**：云端接口地址写错（一直 404），已改正；「测试云端连通性」会真传一张图去试，能识别才显示「可用」。
- **OCR 没启动却静默空跑**：现在依次回退到本地识别 → 云端 API → 视觉模型，并在上传进度里提示「OCR 未就绪」。
