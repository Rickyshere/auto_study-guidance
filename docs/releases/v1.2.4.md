# Auto Study Guidance v1.2.4 更新公告

## 修复
- **点「启动本地服务」毫无反应**：启动命令里混进了一个服务不认识的参数，进程一起来就被拒绝、当场退出，界面自然也看不到任何变化。现在会真的把服务拉起来。
- **启动了也没有反馈**：点下去立刻在右下角浮出进度条，边等边显示「还在等 8010 端口响应，已等 12 秒」，成功变绿、失败变红，失败还会把服务日志的最后几行贴出来（缺模型、端口被占都能直接看出来）。
- **服务明明在跑却识别不出字**：本地 OCR 调的接口地址是旧的，服务回「找不到」被当成空结果吞掉了，于是永远识别出 0 字。地址已按新版服务改正。
- **选了引擎一保存就被改回原样**：在设置里选好识别引擎后，只要点了别的按钮（比如启动服务），选择就被打回上一次保存的值，再点保存反而把新选择覆盖掉。现在只有重新打开设置才会重载。
- **启动失败却显示成功**：现在以服务真实状态为准，没起来就是失败。

## 说明
- 单页扫描件用本地 OCR 约需 20–30 秒，机器内存吃紧时会更慢；追求快可直接用「SoMark Free-OXR 开放 API」。

> 刷新页面即可；桌面版需重启程序。
