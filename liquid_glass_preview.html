深度学习核心架构：梯度传播、自注意力与训练稳定性

在深层前馈网络与序列建模过程中，非线性激活函数与归一化路径直接决定反向传播是否会陷入数值退化。 ReLU 在正半轴导数恒为 1，能够显著缓解深层网络的梯度消失现象 ， 而 Sigmoid 在两端饱和区的导数接近于零，经链式法则连乘后易导致浅层参数更新停滞 。

一、Scaled Dot-Product Attention 缩放与归一化

在多头自注意力计算中，点积 QKᵀ 的方差随向量维度 d_k 线性放大。 通过除以缩放因子 √d_k，logits 分布方差归一化为 1，从而保护 Softmax 处于梯度灵敏区间 。

Attention(Q, K, V) = softmax( (Q · Kᵀ) / √d_k + Mask_causal ) · V scores = torch.matmul(q, k.transpose(-2, -1)) / math.sqrt(d_k) # Var(q·k / √d_k) == 1.0

二、残差恒等通路与 Pre-LayerNorm 结构

残差连接构造 y = F(x) + x 为梯度回传建立低阻高速通道 ； 结合 Pre-LayerNorm 将归一化移入子层分支，能明显提升深层 Transformer 收敛稳定性 。

为什么 Transformer 自注意力需要除以 √d_k？

提示：从向量内积的方差缩放与 Softmax 梯度区分析

键盘 [Space] 翻转 · [←] 需复习 · [→] 已掌握
背面 · 核心定义与溯源

假设 Q、K 各分量为零均值、单位方差独立随机变量，点积方差会放大至 d_k。除以 √d_k 后方差恢复为 1，防止 Softmax 梯度消失。

Var(∑ qᵢ·kᵢ) = d_k ⇒ Var(q·k / √d_k) = 1
